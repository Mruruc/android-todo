# 📝 Android Todo Application

A simple and clean Todo application built using **Kotlin** and **Jetpack Compose**, designed for learning and practicing modern Android UI development with Compose.

## 🚀 Features

- Add, view, and delete todo tasks
- Organized screen navigation using Jetpack Navigation
- Modular and maintainable codebase following best practices
- Custom UI components with Compose
- Light and clean visual theme

## 🛠️ Tech Stack

- **Kotlin** - Programming language
- **Jetpack Compose** - Declarative UI toolkit
- **Android Jetpack** - Navigation, ViewModel (if used later)
- **MVVM-ish Architecture** - Separated concerns: UI, Model, Repository
- **Material Design 3** - Theming and UI components
